# CareLink Server

CareLink Server is the REST API backend for the CareLink mobile healthcare appointment application.

## Features

- User registration
- User login
- JWT-based authentication
- Protected API routes
- User profile management
- Password change
- Healthcare provider discovery
- Provider search
- Provider filtering
- Provider details
- Appointment booking
- Appointment retrieval
- Appointment cancellation
- MongoDB persistence
- Centralized error handling
- Authentication middleware
- Input validation

## Tech Stack

- Node.js
- Express
- TypeScript
- MongoDB
- Mongoose
- JSON Web Tokens
- bcrypt
- Axios
